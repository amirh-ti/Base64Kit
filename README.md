### ✨ Features

- 🔤 **Encode / Decode text to Base64** — full support for Persian, Arabic, emoji, and all Unicode characters
- 📁 **Encode any file to Base64** — images, PDFs, ZIPs, audio, video, and more
- 📥 **Decode Base64 back to a file & auto-download** — with automatic file-type detection from magic bytes
- 🌐 **Bilingual UI** — English & Persian (default: English)
- 🎛️ **URL-safe mode** — replaces `+` and `/` with `-` and `_` for safe use in URLs
- 📋 **One-click copy** — copy the result instantly
- 📱 **Fully responsive** — works great on mobile and desktop

### 🚀 How to Use

1. Click the link above to open the tool
2. Choose the **Text** tab for text, or the **File** tab for a file
3. Paste your input and click **Encode**
4. Copy the output with the **Copy** button

To decode: paste the Base64 string and click **Decode**.
